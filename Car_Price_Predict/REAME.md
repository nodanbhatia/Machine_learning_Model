# 🚘 Project Overview

**Car Price Prediction System** is an end-to-end Machine Learning application designed to predict the **selling price of a used car** based on important vehicle characteristics.

The project combines:

- 🧹 Data preprocessing
- 🔍 Exploratory Data Analysis
- ⚙️ Feature engineering
- 📊 Data visualization
- 🤖 Machine Learning regression
- 📏 Model evaluation
- 🔮 Price prediction
- 🖥️ Interactive Streamlit interface
- 📂 Custom dataset upload

The application allows users to enter vehicle information and obtain an estimated selling price using a trained Machine Learning model.

---

# 🎯 Problem Statement

Buying or selling a used vehicle can make it difficult to determine an appropriate market price.

The objective of this project is to build a Machine Learning model that learns relationships between vehicle characteristics and selling prices.
